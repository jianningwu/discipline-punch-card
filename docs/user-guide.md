## 安装应用

### Windows 安装

1. 从 [Releases](https://github.com/yourusername/discipline-punch-card/releases) 下载 `.exe` 安装程序
2. 双击运行，按照安装向导完成安装
3. 安装完成后，桌面会出现"自律打卡"快捷方式

### Linux 安装

**AppImage（推荐）**:
```bash
chmod +x discipline-punch-card-1.0.0.AppImage
./discipline-punch-card-1.0.0.AppImage
```

**Debian/Ubuntu**:
```bash
sudo dpkg -i discipline-punch-card-1.0.0.deb
```

## 注册与登录

### 注册账号

1. 打开应用，点击"立即注册"
2. 输入用户名（2-20位，支持中英文、数字、下划线）
3. 输入密码（6-32位）
4. 确认密码
5. 点击"注册"按钮
6. 注册成功后自动跳转登录页面

> ⚠️ **注意**：数据存储在本地，不会上传到任何服务器。请妥善保管你的账号信息。

### 登录

1. 输入用户名和密码
2. 点击"登录"按钮
3. 登录成功后进入首页仪表盘

### 注销

- 点击侧边栏底部的"退出登录"按钮

## 首页仪表盘

登录后进入首页仪表盘，你可以看到：

### 欢迎区
- 当前日期、星期
- 个性化问候语（根据时间段变化）
- 打卡进度提示

### 统计卡片
- **打卡项目** - 你的打卡项目总数
- **今日完成** - 今日已完成/总项目数 + 完成率
- **当前连续** - 连续打卡天数
- **最长连续** - 历史最长连续打卡天数

### 今日进度条
- 直观显示今日打卡完成率

### 快速打卡区
- 点击任意打卡项目即可完成/取消今日打卡
- 已完成的项目显示绿色勾号
- 可以添加打卡内容（跳转到详细打卡页）

### 快捷按钮
- 开始打卡 → 跳转到打卡页面
- 查看日历 → 跳转到日历视图
- 查看统计 → 跳转到统计页面

## 每日打卡

打卡页面支持详细的打卡操作：

### 日期导航
- 使用左右箭头切换日期
- 点击"今天"按钮快速回到当天
- 顶部进度条显示当天完成情况

### 打卡操作
1. 点击项目左侧的圆形按钮完成打卡
2. 点击右侧编辑图标展开详情编辑

### 心情记录
- 8种心情可选：😊开心 😌平静 💪充实 😤努力 😴疲惫 😐一般 😢难过 🤩超棒

### 打卡内容
- 在文本框中填写打卡内容
- 例如：运动项目可以记录"跑步5公里"
- 阅读项目可以记录"读《XXX》第3章"

### 修改打卡
- 已打卡的项目可以随时修改内容和心情
- 点击编辑图标 → 修改内容 → 点击保存

### 取消打卡
- 再次点击已打卡项目的圆形按钮即可取消

## 日历视图

### 月视图
- 显示当前月份的打卡热力图
- 颜色越深表示当天打卡项目越多
- 点击某一天查看当天打卡详情
- 今天用蓝色边框高亮标注
- 底部图例说明颜色含义

### 年视图
- 显示全年12个月的打卡概况
- 每个月显示打卡天数和完成率
- 进度条直观展示月度完成情况
- 点击某个月切换到该月的月视图

## 数据统计

统计页面提供丰富的数据可视化：

### 顶部数据卡片
- 今日完成率
- 当前连续打卡天数
- 最长连续打卡天数
- 本月打卡天数

### 近7天打卡趋势（柱状图）
- 显示最近一周每天的打卡数量
- 鼠标悬停查看具体日期和数量

### 项目完成分布（饼图）
- 各打卡项目的完成天数占比
- 内环饼图设计，直观美观

### 完成率变化（面积图）
- 最近7天的完成率趋势
- 渐变填充，视觉效果出色

### 打卡项目排行
- 横向条形图展示各项目完成天数
- 按完成天数从高到低排序
- 进度条颜色与项目颜色一致

## 项目管理

### 查看项目列表
- 所有活跃的打卡项目列表
- 默认项目标记"默认"标签
- 自定义项目可编辑和删除

### 添加项目
1. 点击"添加项目"按钮
2. 填写项目名称（必填）
3. 填写项目描述（可选）
4. 选择图标（32种Emoji可选）
5. 选择颜色（12种颜色可选）
6. 点击"添加项目"

### 编辑项目
1. 鼠标悬停在项目上
2. 点击编辑图标
3. 修改项目信息
4. 点击"保存修改"

### 删除项目
1. 鼠标悬停在项目上
2. 点击删除图标
3. 确认删除

> ⚠️ 删除操作不可撤销，相关的打卡记录可能丢失。
